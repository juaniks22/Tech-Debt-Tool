Principios de Arquitectura Limpia y Estabilidad

Inestabilidad (I)
I = Ce / (Ca + Ce)

Mide la resiliencia al cambio. I = 0 es maximalmente estable (nadie de quien dependa). I = 1 es inestable.

Abstracción (A)
A = Na / (Na + Nc)

Proporción de interfaces o tipos abstractos (Na) sobre el total de componentes concretos (Nc).

Distancia Normalizada (D)
D = |A + I - 1|

Distancia a la Secuencia Principal ideal. Si D > 0.5, el módulo cae en zona de dolor o inutilidad.
